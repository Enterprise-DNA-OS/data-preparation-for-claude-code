# /add-action

Read CLAUDE.md. Run `npm run prep -- add-action --json` with the required options below. Use the actual output to answer.

--title=Task --owner=Name --due=YYYY-MM-DD --actor=Name

Name the operator with --actor. Read the existing record first. Do not guess missing fields.

Ambiguous names list candidates and exit 1. Ask which record the operator means.
