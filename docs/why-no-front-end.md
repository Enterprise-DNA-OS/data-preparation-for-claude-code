# Why no front end

The weekly task is to bring files in, apply rules, resolve exceptions and explain the result. The database and command recipes hold that work. The agent translates the operator's request into those commands.

The base renders branded HTML snapshots for review and printing. A snapshot does not refresh by itself. There is no drag-and-drop workflow designer, mobile editing, concurrent staff workspace or embedded database sharing. A local operator can run without a live database service, but coding agents and installed dependencies have their own connection needs.

If those screens or live connections matter, Enterprise DNA builds and runs the version your business needs through Omni by Enterprise DNA. One setup fee, then a retainer. The database remains yours.
